# ai-pddl-planning-project
Academic AI planning projects using PDDL

### Sokoban
- PDDL domain for Sokoban puzzle with implemented state representation, movement actions preconditions, and effects.

### Tower of Hanoi 
- PDDL domain for Tower of Hanoi problem with implemented legal disk movement and state transitions.

Both problems tested using automated PDDL Editor and automated planning engines.
